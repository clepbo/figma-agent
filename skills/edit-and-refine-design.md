# Edit & Refine Design Skill

Use this skill when asked to update, edit, rebrand, or refine existing designs in Figma.

## Instructions
1. Inspect selected elements or document tree using `get_selection` / `get_document_tree`.
2. Analyze the node hierarchy (find frame containers, background colors, text labels, buttons).
3. Execute contextual updates:
   - **Re-theming**: Update background fills, text fills, and stroke colors across child layers.
   - **Auto-Layout Refactoring**: Turn static frame into responsive Auto-Layout with defined padding and item spacing.
   - **Feature Addition**: Insert new UI elements (e.g. badges, input fields, action buttons) into existing containers at appropriate positions.
   - **Text & Copy Updates**: Update typography, font sizes, line heights, or text strings.
