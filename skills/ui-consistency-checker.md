# UI Consistency Checker Skill

Use this skill to audit and standardize design consistency across canvas frames.

## Instructions
1. Inspect selection node tree.
2. Standardize corner radii (e.g. 8px for buttons/inputs, 16px for cards, 24px for modals).
3. Standardize padding to an 8pt spatial grid (8px, 16px, 24px, 32px, 48px).
4. Verify text contrast against background surface colors.
