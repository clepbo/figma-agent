# Generate Responsive Variants Skill

Use this skill to convert desktop frame layouts into mobile (375px) or tablet (768px) responsive layouts.

## Instructions
1. Inspect the selected desktop frame.
2. Read child layout structures (headers, hero grids, multi-column cards).
3. Convert horizontal multi-column layouts into vertical single-column stacks with adjusted padding (16px) and resized frame width (375px).
