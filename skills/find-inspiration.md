# Inspiration Search & Translation Skill

Use this skill when asked to find inspiration, look up design references, or emulate a visual style (e.g. "Glassmorphism SaaS", "Neubrutalism E-commerce", "Minimalist Fintech").

## Instructions
1. Search and extract style tokens for the requested theme:
   - Primary, Secondary, Background, Surface, and Accent Hex Colors.
   - Typography pairs (Headings & Body).
   - Card border radius, stroke thickness, and shadow/elevation effects.
2. Build a Visual Inspiration Swatch Frame on canvas with color swatches, typography samples, and sample UI elements.
3. Apply the extracted style tokens to generate candidate UI layouts.
