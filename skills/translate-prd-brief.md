# PRD & Brief Translator Skill

Use this skill when provided with a PRD text, user stories, or feature specification.

## Instructions
1. Parse the input text to extract:
   - Product Name & Category (e.g. SaaS, Fintech, E-Commerce).
   - Core User Flow & Screens required.
   - Screen hierarchy (Header/Nav, Hero, Feature Grid, Data Tables, Form Fields, Action CTAs).
   - Brand Tone & Visual Style (Dark/Light, Primary Brand Color, Font preferences).
2. Generate structured multi-screen canvas layouts in Figma using Auto-Layout.
3. Ensure proper visual hierarchy, contrast ratios, and consistent padding.
